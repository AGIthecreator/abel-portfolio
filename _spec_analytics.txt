==================================================
OBJETIVO
========

Crear una experiencia interactiva premium para demostrar cómo funciona una automatización real.

NO debe parecer:

* una página de servicios tradicional
* un tutorial
* un dashboard empresarial
* una infografía
* una presentación de diapositivas
* un videojuego infantil
* una demo tecnológica genérica
* una landing llena de texto

Debe sentirse como una pequeña herramienta/producto interactivo de AGI TheCreator.

Concepto central:

"Una automatización no es simplemente hacer algo automáticamente.
Es conseguir que un proceso sepa qué hacer en cada situación."

Idea secundaria:

"Primero el proceso. Después la herramienta."

La experiencia debe demostrar:

ENTRADA → DECISIÓN → ACCIÓN → SEGUIMIENTO → RESULTADO

Y también:

AUTOMATIZACIÓN → EXCEPCIÓN → ¿SE PUEDE RESOLVER? → ACCIÓN / PERSONA

La interacción es más importante que la explicación.
